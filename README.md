## 📋 About

SprintFlow is a Kanban-style task management tool built entirely with vanilla JavaScript — no frameworks, no libraries. Tasks can be organized across columns, moved via drag-and-drop, and are saved to localStorage for persistence between sessions.

---

## ✨ Features

- **Kanban Board** — Organize tasks across multiple columns (To Do, In Progress, Done)
- **Drag & Drop** — Move tasks between columns using native HTML5 drag-and-drop API
- **Local Persistence** — Tasks are saved to `localStorage` and restored on page reload
- **Task Management** — Create, edit, and delete tasks
- **Clean Dark UI** — Minimal, focused interface without visual clutter
- **Zero Dependencies** — No external libraries or build tools required
